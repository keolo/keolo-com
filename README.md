# Keolo.com

## Workflow

1. Build site and run development server: `hugo server -D`
2. Create a new post: `hugo new posts/<post-name>.md`
3. Preview site: http://localhost:1313/
4. Approve post: `draft: false`
5. Deploy site: `git commit -am "message" && git push origin master`

## Usage

- Edit configuration: `hugo.yaml`
- Edit theme: `cp themes/PaperMod/layouts/partials/header.html layouts/partials/header.html`
